# Marketra 📈

A simple and lightweight cryptocurrency dashboard built with Python and Kivy.

## ✨ Features (Version 1)
- Fetches real-time prices for Bitcoin (BTC), Ethereum (ETH), and Solana (SOL) from the CoinGecko API.
- Clean and responsive user interface built with Kivy.
- Object-Oriented Programming (OOP) architecture for data handling (e.g., the `Coin` class).
- Uses background threading for network requests to prevent the UI from freezing.

## 🛠 Tech Stack
- **Language:** Python 3
- **UI Framework:** Kivy
- **Networking:** Requests

## 🚀 How to Run
First, install the required dependencies:

```bash
pip install kivy requests
python main.py
```
